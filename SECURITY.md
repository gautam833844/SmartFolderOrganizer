# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within SmartFolderOrganizer, please report it privately.

- **Email**: security@smartfolderorganizer.org
- Please do NOT create public GitHub issues for security vulnerabilities.
- Provide full reproduction details and impact analysis.
- Vulnerabilities will be acknowledged within 48 hours and patched in a security release.
